# Interview Response Frameworks

## STAR
- Situation
- Task
- Action
- Result

## OODA
- Observe
- Orient
- Decide
- Act

## Combined approach for technical interviews
- Situation = Observe
- Task = Orient
- Action = Decide + Act
- Result = measurable feedback/outcome

## Fabio examples
1. **OpenStack final project**
   - STAR: built lab environment, stabilized networking stack, documented reproducible deployment.
   - OODA: observed integration failure patterns, oriented on dependencies, decided staged rollout, acted with iterative validation.

2. **Amazon escalation / verification workflow**
   - STAR: managed sensitive escalations, applied strict verification controls, reduced repeat contacts through clear resolution messaging.
   - OODA: observed compliance risk, oriented on policy boundaries, decided evidence-first triage, acted with documented escalation paths.

3. **TwoS infrastructure leadership**
   - STAR: led operations modernization, drove automation with Ansible, improved delivery consistency while mentoring apprentices.
   - OODA: observed recurring manual failures, oriented on process bottlenecks, decided automation roadmap, acted through phased implementation.
