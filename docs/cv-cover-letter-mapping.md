# CV to Cover Letter Mapping

## Method
1. Extract role requirements from the job description.
2. Map each requirement to concrete CV evidence.
3. Convert evidence into STAR fragments.
4. State business impact and motivation.

| Requirement | CV Evidence | Cover Letter Argument |
|------------|-------------|----------------------|
| Cloud transformation delivery | TwoS: Docker/Kubernetes runtime support, Ansible automation, mentoring | I can lead modernization while improving reliability and team execution. |
| Customer-facing consulting communication | Amazon/Webhelp: escalation, verification, compliance-sensitive communication | I translate technical complexity into trusted stakeholder outcomes. |
| Linux/OpenStack depth | B1 Systems and I/P/B: Linux consulting, OpenStack, KVM/QEMU, OVS, MaaS | I bring practical platform engineering depth for production cloud environments. |
| Security and resilience mindset | F.R.A.U.D./INSR framework | I combine technical controls with human-risk analysis for safer systems. |
